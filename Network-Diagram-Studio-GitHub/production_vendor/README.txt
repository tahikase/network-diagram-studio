Network Diagram Studio - production third-party architecture icons
Retrieved: 2026-09-15

SCOPE AND INTEGRATION
Fifteen local, authentic product/architecture icons: five AWS, four Oracle OCI,
and six Kubernetes architecture resource icons.
AWS: Virtual Private Cloud, EC2, Elastic Load Balancing, Site-to-Site VPN,
Direct Connect.
Oracle OCI: Virtual Cloud Network, Virtual Machine, Load Balancer,
Dynamic Routing Gateway.
Kubernetes: Pod, Service, Ingress, Network Policy, Endpoints, Node.
These six additions are resource-specific official architecture artwork, not
standalone project logos or generic substitutes for commercial vendors.

These files are part of the current production browser and Windows app package.
Keep this complete folder beside the root index.html. catalog.js and
vendor-icons.js register the icons with the native resource and icon catalogs.
The included capture support preserves these icons in Screenshot and exports.
No separate palette UI, CSS changes, network calls, analytics, or remote images.
Use the existing Resources, All icons, Search everything, Favorites, native
editable node properties, JSON persistence, PNG/SVG export and Screenshot.
Resource and icon IDs are stable vendor-aws--*, vendor-oci--*, and
vendor-kubernetes--* identifiers. The original nine IDs/assets are unchanged.
JSON files retain those IDs; open them in the current production package with
this catalog present. Older application versions may not recognize these types.

ARTWORK HANDLING
Fourteen SVG files are byte-for-byte copies/extracts of official sources.
AWS paths use Architecture-Service-Icons_07312026, Compute or
Networking-Content-Delivery, 48. Their native 64x64 viewBox is preserved.
OCI VCN = PowerPoint ppt/media/image29.svg, nearest group label VCN, slide18.
OCI VM = ppt/media/image56.svg, group label Virtual Machine, slide29.
OCI Load Balancer = ppt/media/image60.svg, group label Load Balancer, slide29.
The official embedded VCN artwork has its own Sienna shade; it is preserved
exactly, not normalized to another version of the written style palette.

OCI DRG = OCI Library.xml entry "Networking - Dynamic Routing Gateway DRG".
The supplied DRG is an mxGraph stencil rather than an embedded SVG file.
It is converted mechanically to SVG using its original M/L/C path coordinates,
layer order, group offsets, original fills and 100-unit stencil scale. There
is no hand-drawn replacement, shape simplification or recoloring. Its separate
source text label is supplied by the native resource node instead.
catalog.json records exact source entries, conversion notes and SHA-256 hashes.
The browser wraps original SVG content in native symbols and namespaces IDs/
internal paint references solely to prevent collisions. Geometry, aspect
ratios, colors, gradients and stop values remain unchanged.
Downloaded assets were checked for external scripts, image links and URLs;
none are needed. No project or customer information was sent to vendor sites.
