# Icon licenses

Three icon sets ship inside this app: one from Microsoft, and two that are
original artwork authored for this project.

---

# 1. Microsoft Azure architecture icons

The 714 SVG icons bundled in this app come from the official
**Microsoft Azure architecture icons** set (`Azure_Public_Service_Icons_V24`).
Attribution and usage terms below are quoted directly from
`Microsoft_Terms_of_Use.pdf` shipped with the icon set.

## Terms (quoted)

> Microsoft permits the use of these icons in architectural diagrams, training
> materials, or documentation. You may copy, distribute, and display the icons
> only for the permitted use unless granted explicit permission by Microsoft.
> Microsoft reserves all other rights.

### Do's
- Use the icons to illustrate how products can work together
- In diagrams, include the product name somewhere close to the icon
- Use the icons as they would appear within Azure

### Don'ts
- Don't crop, flip, or rotate icons
- Don't distort or change icon shape in any way
- Don't use Microsoft product icons to represent your product or service

## What this app does

- Renders each icon **as-is** (no crop, flip, rotation, or shape distortion —
  we only scale it uniformly to fit the node)
- Displays the resource type label ("Application Gateway", "VM", …) next to
  every icon, per the "include the product name" guidance
- Uses the icons **only** to depict Azure resources within a customer
  architectural diagram

The icons remain Microsoft's property. This app is a diagram authoring tool —
not a replacement for or representation of any Azure product.

Source of the icon set: Microsoft's official Azure architecture icons,
`Azure_Public_Service_Icons_V24`. The generated sprite is included, so a normal
build does not require the original icon download or its original location.

Refer to the accompanying `Microsoft_Terms_of_Use.pdf` and `Azure_Icons_FAQ.pdf`
for the authoritative version of these terms.

# 2. On-premises icon set

The 77 SVG icons under `src/icons/custom-svg/On-premises/` are **original
artwork**, generated by `scripts/author-onprem-icons.mjs` and authored for
this project. No Cisco icon library, Visio stencil or draw.io shape data was
opened, copied or traced. What they reuse is unprotectable convention — router
as a puck with opposed arrows, firewall as a brick wall, WAN as a cloud.

# 3. Microsoft 365 icon set

The 37 SVG icons under `src/icons/custom-svg/Microsoft 365/` are **original
artwork**, generated by `scripts/author-m365-icons.mjs` on the same 18x18
grid and in the same house style as the On-premises set above.

## Why they are drawn rather than downloaded

Microsoft publishes two different things, and neither one is a downloadable
pack of Microsoft 365 product logos:

| | Governed by | Redistributable |
|---|---|---|
| Product **brand marks** — the SharePoint / OneDrive / Teams / Outlook / Copilot tiles | [Microsoft Trademark and Brand Guidelines](https://www.microsoft.com/legal/intellectualproperty/trademarks) | ❌ no — requires express permission |
| **Microsoft 365 architecture icons** | same terms of use as the Azure V24 set | ✅ yes — but see below |

The architecture pack was evaluated and **rejected**. It is not a logo set:
it contains roughly 160 generic concept glyphs (Mail, People Team, Cloud
Arrow Up, Organization, Bot) redrawn in six brand colourways across three
tints — 963 files, about 1.1 MB, and not one recognisable product mark. A
node labelled *SharePoint Online* would have worn a teal `Organization`
glyph.

So each symbol here is drawn from scratch using the product's conventional
**functional motif** — an envelope for mail, a cloud for cloud storage, a
sparkle for an AI assistant, a shield for a security product, a barrier for
Conditional Access. Motifs of that kind are unprotectable; the brand marks
are not copied, traced, or approximated.

> ⚠️ Do not "improve" this set by dropping in the real product logos scraped
> from a CDN, Wikimedia, or a community GitHub icon repo. They are trademarks
> and this file is redistributed.

## Substituting official art later

The file name becomes the icon id, so if you obtain the official product art
through Microsoft's own brand channels, drop the SVGs into
`src/icons/custom-svg/Microsoft 365/` using the same names and run
`npm run build:icons -- "C:\path\to\Azure\Icons"`. Review the regenerated sprite
and manifest as a versioned source change.
